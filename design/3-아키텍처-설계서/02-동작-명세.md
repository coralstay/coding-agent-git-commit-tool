# 3.02 동작 명세

> 작성 전

훅마다 입력에서 결과까지 어떤 순서로 판단하는가.

## 담을 내용

- [ ] `prepare-commit-msg` — 재생 · 병합 면제, 에디터 경로 거부, 검증 마커
- [ ] `commit-msg` — 형식 · 길이 · `Fixes` · 브랜치 `Task-Id` · `AI-Model` 게이트
- [ ] `post-commit` — 트레일러 계산 순서, 중복 판정, `--amend` 재진입 가드
- [ ] 토큰 귀속 알고리즘 — 응답 묶기, 대상 경로 대조, 귀속 기록(decision-27)
- [ ] 재생 · 병합 · rebase 같은 이력 연산에서의 동작(doc-19)

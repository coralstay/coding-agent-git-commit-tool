# 3.02 동작 명세

> 작성 전

훅마다 입력에서 결과까지 어떤 순서로 판단하는가.

## 담을 내용

- [ ] `prepare-commit-msg` — 재생 · 병합 면제, 에디터 경로 거부
- [ ] 메시지 검증 — 형식 · 길이 · `Fixes` · 브랜치 `Task-Id` · 모델 게이트
- [ ] 트레일러 삽입 — 계산 순서, 키 단위 중복 판정(decision-19), `interpret-trailers --in-place`
- [ ] `AI-Agent` 모델 판정 — 트랜스크립트 경로 슬러그, `message.model` 읽기, fail-open
- 토큰 귀속 알고리즘은 다루지 않는다 — 측정은 범위 밖이다(decision-31)
- [ ] 재생 · 병합 · rebase 같은 이력 연산에서의 동작(doc-19)

# 2.04 품질 요구사항

> 작성 전

신뢰성 · 감사 가능성 · 이식성 같은 품질 요구사항.

## 담을 내용

- 최상위 NFR-004 · NFR-005(토큰 관측)는 받지 않는다 — 토큰 계량 컴포넌트로 넘겼다(decision-31)
- [ ] 견고성 — 비 UTF-8 로케일, 셸 메타문자, `python3` 부재, 설정 파일 읽기 실패
- [ ] 감사 가능성 — 파일 하나로 훅 하나가 읽힌다(decision-16)
- [ ] 개인정보 — 세션 ID · 인증 정보 · 대화 내용을 커밋에 남기지 않는다

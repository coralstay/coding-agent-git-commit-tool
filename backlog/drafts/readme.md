# drafts

**무엇인가**: 아직 사용자 승인을 받지 못했거나, 실행하지 않기로 하고 아이디어만
남겨둔 계획 초안을 담는다(현재 DRAFT-1). task와 달리 곧바로 실행되지 않으며, 검토와
승인을 거쳐야 정식 태스크가 된다.

**언제 쓰나**: (1) plan mode에서 세운 계획을 프롬프트로 먼저 보여주고 승인받은 뒤
그 결과를 기록할 때, (2) 지금 당장 코드로 구현하지는 않지만 나중을 위해 아이디어만
남겨두고 싶을 때(예: DRAFT-1 "다른 AI 코딩 도구용 토큰 실측 채널 지원" — 아직 그런
도구가 없어 구현 대신 draft로만 존재). 이 저장소는 "가능성이 있다고 코드에 스텁을
미리 만들지 않는다"는 원칙이 있어, 그런 경우 draft가 유일한 기록 수단이다.

**관련 명령**:

- `backlog draft create "title" --description "..."` — 새 초안 생성
- `backlog draft promote DRAFT-N` — 승인된 초안을 정식 태스크(GF-N)로 승격
- `backlog task demote GF-N` — 반대로 태스크를 다시 draft로 되돌림
- `backlog draft list` — 대기 중인 초안 목록 조회

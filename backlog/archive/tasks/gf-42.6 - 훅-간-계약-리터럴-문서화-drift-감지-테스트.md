## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
commit-msg/pre-commit/post-commit/pre-push는 여러 파일이 반드시 같은 값을 써야 맞물려 동작하는 '계약' 성격 리터럴을 공유 파일 없이 각자 하드코딩하고 있다: 마커 파일명(.gitformat-verified, 3개 파일), Task-Id 정규식 앵커링 패턴과 TASK_PREFIX/BRANCH 계산 로직(commit-msg/post-commit), 언어 감지 마커 5종(pre-commit/pre-push). 이 목록을 backlog 문서로 정리하고, 각 관련 파일에 '다른 파일 X도 동일 값을 씀' 상호참조 주석을 추가하고, 이 계약들이 실제로 지켜지는지 실행으로 검증하는 bats 케이스를 보강한다(GF-23/25가 일부 검증 중이므로 빠진 조합만 추가). 파일별 리터럴 지역화 서브태스크 5개가 모두 끝난 뒤 진행한다(GF-42 부모 태스크의 다른 서브태스크들에 의존).

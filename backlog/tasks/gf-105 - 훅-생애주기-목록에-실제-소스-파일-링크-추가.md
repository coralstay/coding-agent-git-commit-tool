## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
사용자가 claude-rails README의 관례("훅 이름을 누르시면 실제 소스 파일로 이동합니다")를 참고해, git-format README의 훅 생애주기 목록(pre-commit/commit-msg/post-commit)에도 각 훅 이름을 실제 구현 파일(hooks/pre-commit, hooks/commit-msg, hooks/post-commit)로 가는 마크다운 링크로 만들라고 요청했다. pre-commit 항목이 언급하는 hooks/checks/<lang>.sh도 실제 구현 위치(hooks/checks/)로 링크한다.

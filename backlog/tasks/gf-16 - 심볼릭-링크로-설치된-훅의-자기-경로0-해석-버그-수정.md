## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
dirname "$0"이 심볼릭 링크를 해석하지 않아, template/(init.templateDir, GF-9)로 설치된 신규 저장소에서 HOOK_DIR/CHECKS_DIR/Hooks-Commit이 새 저장소 자신의 .git/hooks를 잘못 가리켰다. pre-commit의 언어별 체크 스크립트가 조용히 전부 스킵되고, post-commit의 Hooks-Commit이 git-format이 아니라 그 저장소 자신의 커밋 해시를 가리키는 심각한 버그. core.hooksPath(install.sh 기본 경로, GF-8)는 실제 파일을 직접 가리켜 영향 없음. GitHub fresh clone + git init --template 실사용 테스트 중 발견.

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
pre-commit/post-commit/commit-msg 세 훅에 resolve_self() 심볼릭 링크 해석 함수 추가. template/(GF-9) 심볼릭 링크 설치 시 언어별 체크가 전부 조용히 스킵되던 것과 Hooks-Commit이 엉뚱한 저장소를 가리키던 것을 수정. GitHub fresh clone + git init --template로 실제 npm lint 통과/차단, 정확한 Hooks-Commit을 재검증. core.hooksPath(비-심볼릭) 경로는 회귀 없음 확인.
